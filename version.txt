update_log:"# ChatDS 15.4 更新说明

## 重要修复

### 群组黑屏
点击群组后整页白屏，返回键也失效，只能再按一次退出。
原因是 CharacterEditor 从 CharacterPanel 抽离时带走了 Field 组件，
但未导出也未重新导入，渲染时 Field 为 undefined 导致 React 整树崩溃。
现已补上导出与导入，问题解决。
同时新增全局错误边界，日后任何渲染异常都会显示具体错误信息与堆栈，
不再出现无提示的白屏，并提供一键复制与重新加载。

### 覆盖安装后对话丢失
WebView 只开启了 DomStorage，未开启 Database，
导致 IndexedDB 在部分系统版本上不持久化，覆盖安装后对话与附件全部清空。
现已开启 setDatabaseEnabled，并允许系统备份，
备份规则包含 WebView 存储目录与数据库，排除缓存目录。

## 新增功能

### 角色卡系统
- 新建对话时先选择类型：普通对话 / 角色聊天 / 群组
- 角色支持头像上传（自动转 base64）、一句话简介、
  人设设定、开场白、说话风格、永久记忆六项配置
- 永久记忆会写入每一轮的 system prompt，
  适合放长线设定、称呼偏好、剧情锚点
- 支持生成 ChatDS:// 开头的 base64 分享串，
  一键复制分享文案，对方粘贴即可导入
- 选择角色页可直接新建角色，保存后立即开始对话
- 聊天界面每条回复上方显示角色头像与名称

### 群组模式
- 可创建包含多个角色的群组，并设定共同场景
- 群组对话强制模型输出 JSON：
  {\"replies\":[{\"character_id\":\"...\",\"content\":\"...\"}]}
- 解析时以角色 id 为唯一判断依据，
  一条回复里多个角色发言会被拆成多个独立气泡
- 解析器容忍代码块包裹、前后杂质与非法字段

### 第三方接入
- 支持 DeepSeek 官方、OpenAI、Anthropic、硅基流动、
  自定义 OpenAI 兼容地址，或直接禁用某项能力
- 聊天、语音合成、语音识别三项可分别配置供应商与 Key
- 每项支持留空回落到全局 DeepSeek Key
- 聊天支持流式输出开关，可切换逐字返回与整段返回
- 禁用某项能力时，界面上对应的按钮会自动隐藏
- 高级模式默认关闭，普通用户只需填一个 Key 即可使用

### 检查更新
- 启动后延迟检查，不阻塞首屏加载
- 依次尝试 GitHub 直连与多个镜像，任一成功即可
- 有更新时弹窗展示 Markdown 更新日志与下载按钮
- 每个设置模块底部均可手动检查

### 存储管理
- 环形图展示占用分布：消息、文件、语音缓存、下载缓存、配置
- 每类可单独清理，危险操作需两次点击确认
- 按对话逐条删除，展示消息数、占用大小、附件数量
- 删除整个对话或全部清除需三次确认，最后一步等待 5 秒
- 导入完成后自动清理下载缓存，避免长期占用

## 改进

### 导入导出
- 支持粘贴 DeepSeek 导出的下载链接直接导入
- 下载与解析两阶段进度实时显示，进度只增不减
- 进度条提升为全局组件，关闭设置页依然可见，完成自动隐藏
- 解析器新增进度回调，按已处理字节数回报
- 原生读取改为 4 线程并发 + 8MB 预读缓存 + 常开文件句柄，
  大文件导入从数十分钟缩短到一分钟内
- 会话写入 IndexedDB 改为批量提交，减少事务次数

### 语音
- 修复朗读无声：之前把 WAV 文件头当成 PCM 采样播放，
  现已改为直接交给音频元素播放
- 音色只保留官方支持的 stella 与 tide，
  修复选择音色后仍然使用默认音色的问题
- 朗读结果本地缓存，重复朗读同一段内容不再消耗额度
- 修复语音识别无法上传音频：桥接层补充了 FormData 序列化

### 界面
- 「数据管理」并入「存储」，导入导出与清除集中在一处
- DeepSeek API Key 输入框移到「通用设置」顶部
- 设置各模块改用不同的 SVG 图标，不再是同一个图标
- 新建对话选择卡片、角色图标等全部改为内联 SVG，移除 emoji
- 导航栏左右增加箭头，提示可横向滑动查看
- 设备类型可手动指定手机 / 平板布局
- 每个设置模块底部都有关于卡片，显示版本、版权与检查更新
- 角色欢迎页显示当前角色的头像与名称
